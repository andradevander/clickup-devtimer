# Start tracking

Click the timer in the **status bar** (or run **ClickUp DevTimer: Select / Start Task**) and pick a task. Your recent tasks and tasks in an active status show up first.

While the timer runs:

- **Only active time counts.** After a few idle minutes the timer pauses itself and resumes when you get back.
- **Branch detection.** Check out a branch like `feature/CU-86bx123-fix-login` and DevTimer offers to start the timer on that task.
- **Finish and sync.** Open the timer menu from the status bar to pause, switch tasks or send the time to ClickUp.
- **Offline safe.** Entries that fail to sync are queued and retried automatically.
