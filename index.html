Built for developers

Honest hours, zero friction

Everything happens in the status bar. No dashboards to babysit, no timers you forget to stop.

Status-bar first

Pick a task, start, pause and sync without leaving the editor. Your current task and elapsed time are always one glance away.

Smart idle detection

The timer pauses when you step away and resumes when you're back. Idle time is never logged, so your hours reflect real work.

Git branch detection

A branch like feature/CU-86bx123 suggests starting the timer on that exact task automatically.

Crash-safe & offline-ready

State is saved to disk and time entries are queued and retried automatically — close the editor or lose Wi-Fi, nothing is lost.

Multi-window aware

One timer shared across all your VS Code windows. Activity in any window counts toward the same task.

Rounding & rules

Round sessions to the nearest 5 minutes, drop tiny entries, add descriptions, and get nudged on long sessions — your way.

Up and running in a minute

Getting started

Connect your ClickUp account once with a personal token — stored only in your OS keychain.

1

Install

Grab ClickUp DevTimer from the VS Code Marketplace (or Open VSX for Cursor / VSCodium).

2

Get your token

In ClickUp: Settings → Apps → API Token → Generate. It looks like pk_12345_…

3

Paste it

Run ClickUp DevTimer: Set Personal Token from the Command Palette and pick your workspace.

4

Start tracking

Select a task from the status bar and go. The timer handles the rest while you code.

Stop guessing your hours.

Let the editor track the time while you focus on the code. Install ClickUp DevTimer and sync accurate hours straight to ClickUp.
